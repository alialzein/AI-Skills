# Vocabulary - naming what a reference shows

People bring a screenshot or a reel and say "like this". Name each pattern before anything else: a named pattern can be briefed in one sentence, searched, built and reviewed.

## Surfaces and layout

| Name | What it is |
|------|-----------|
| **Glassmorphism** ("frosted glass", "glass UI") | Translucent surfaces with background blur over a coloured ground, a thin light border, large radii |
| **Liquid glass** | Apple's 2025 variant: glass that refracts and tints with what is behind it |
| **Dark glass** | A dark translucent surface used in BOTH themes, usually for a tab bar, so light effects have something to shine against |
| **Gradient mesh / aurora ground** | Two or three large soft colour fields behind the content |
| **Gradient orbs** | Blurred colour spheres placed behind a glass card as decoration |
| **Bento grid** | Cards of different sizes packed in a grid like a lunch box |
| **Hero card** | One large card that carries the screen's key number, a change chip and a trend line |
| **Stat tile / KPI tile** | Icon chip, label, big number, delta |
| **Delta chip** | The small "+31 % vs last week" pill |
| **Sparkline** | A tiny chart with no axes, inside a card |
| **Floating sidebar** ("inset sidebar", "detached panel") | A rounded panel with a gap on all sides, not a column glued to the edge |
| **Icon rail** | The collapsed sidebar: icons only, with tooltips |
| **Floating top bar** | A rounded glass strip, sticky, content scrolling under it |
| **Veil / scroll mask** | The fade that hides content passing above or beside a floating bar |

## Phone

| Name | What it is |
|------|-----------|
| **Floating tab bar** ("floating pill bottom navigation") | A detached rounded bar above the content |
| **Sliding active indicator** | The highlight that travels to the tapped tab |
| **Bell / hump indicator** | A line along the bar's edge that rises in a bell over the active tab |
| **Notched / curved tab bar** | The active icon pops out of a curved cut in the bar |
| **Neon line** | A stroke drawn as light: near-white core, coloured stroke, soft bloom |
| **Bottom sheet** | A panel that rises from the bottom over a dimmed, stepped-back page |
| **Drag handle** | The short bar at the top of a sheet |
| **Segmented control** | Two to four options in one pill (Today / Week / Month) |
| **Safe area** | The parts of the screen the system owns (notch, home indicator) |

## Controls and identity

| Name | What it is |
|------|-----------|
| **Segmented OTP input** ("PIN code input") | One box per digit, auto-advance, paste fills all, auto-verify |
| **Stepper / status tracker** | Paid -> Packing -> Sent, with done steps filled and the connector drawn |
| **Command palette** | The Ctrl/Cmd-K search that opens over everything |
| **Portrait card** | A card led by a person's picture, with the name over a gradient at its foot |
| **Identity header** | Large avatar, name as heading, role chip - the top of a profile page |

## Motion

| Name | What it is |
|------|-----------|
| **Fade and rise** | Content fades in while lifting ~10 px |
| **Open from origin** ("container transform", the Mac / iOS feel) | The destination grows out of the item that was pressed |
| **Shared-axis slide** | Deeper pages enter from one side, Back reverses |
| **Stagger / cascade** | Items land one after another, 30-50 ms apart |
| **Count-up** | A number animating to its value |
| **Draw-on** | A line or ring drawn by animating its dash offset |
| **Breathing** | A slow, small pulse of glow or scale |
| **Glint** | A short highlight travelling along a line |
| **Micro-interaction** | A small state change that confirms an action (a box flipping, a button turning into a check) |

## AI surfaces

| Name | What it is |
|------|-----------|
| **Rich card in a bubble** | The answer carries a designed card (a quote, an order, a product), not a paragraph |
| **Work log / activity timeline** | "What the agent did": icon, sentence, time, appearing one by one |
| **Context panel** | The thing the chat is about, beside the chat, filling in as the conversation goes |
| **State line** | Ready / Thinking / Working / Waiting for you, under the assistant's name |
| **Typing indicator** | Three dots while the first words are awaited |

## One-sentence briefs (pattern)

"A glassmorphism dashboard on a gradient mesh, a floating sidebar and top bar with a veil, a bento of stat tiles under one hero card; on the phone a dark-glass floating tab bar with a neon bell indicator; fade-and-rise page opening, open-from-origin for cards, charts that draw on."
