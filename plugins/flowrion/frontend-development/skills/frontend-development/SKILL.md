# Frontend development

Build interfaces that work for everyone who uses them.

1. Follow the existing components and design tokens; do not add a second way to do the same thing.
2. Make it accessible: real labels, keyboard access with a visible focus, contrast of at least 4.5:1, state shown in words and not by colour alone.
3. Handle every state: loading, empty, error, and partial data.
4. Keep it responsive down to a narrow phone width without sideways scrolling.
5. Keep secrets and authorization on the server; the browser shows what the server allows.
6. Test the behaviour a person sees, and check the page in both light and dark themes if the product has them.
